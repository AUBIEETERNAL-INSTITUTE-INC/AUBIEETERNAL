## Topic

Knowledge that stays in one house is not yet sovereign. Core graduates have a duty to help plant it elsewhere.

## The Steelman Prompt

What is the strongest argument that requiring 'distribution' turns education into missionary work instead of personal growth?

## Example

After completing Core v67, the family helps their neighbors (the Garcias) clone the repo onto a used laptop, run the first courage lesson together, and log the first coherence score. This counts toward the parent's capstone.
