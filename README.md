## ⚡ Reliability — Verified, Not Just Running

The swarm runs 24/7. Quality is monitored continuously.

**HermesBench** (`hermesbench_integration.py`) — 7 AUBIEETERNAL-specific recipes that benchmark the complete stack, not just the model. Tests tutor handoff integrity, epistemic provenance, polyvagal safety boundaries, Bitcoin anchor consistency, state persistence across restarts, wonder spike tracking, and output zero-drift.

**Epistemic Drift Detector** (`epistemic_drift_detector.py`) — monitors four quality signals over time: coherence trend, truth score trend, steelman variance, and confidence calibration. Detects gradual degradation before it damages the Epistemic Commons.

```bash
# Install HermesBench
pip install git+https://github.com/verkyyi/hermesbench.git

# Run reliability suite
python hermesbench_integration.py

# Check for epistemic drift (GREEN / YELLOW / RED / ALARM)
python epistemic_drift_detector.py

# Save quality baseline after a known-good period
python epistemic_drift_detector.py --baseline

# CI integration — exits nonzero on RED or worse
python epistemic_drift_detector.py --ci --fail-on RED
```

Wire both into `COMMIT_EPISTEMIC.sh` for automatic nightly quality gates.
